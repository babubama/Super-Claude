# Super-Claude: скилл для создания игр

Скилл для Claude, который превращает короткий запрос вроде «игра про кота-прыгуна» в готовую мини-игру в одном HTML-файле. Открывается в браузере без установки, работает на телефоне и на ПК.

## Что внутри

```
game-dev/
├── SKILL.md              # правила скилла: как Claude делает игру
└── templates/
    └── game-loop.html    # рабочий каркас игры: цикл, ввод, звук, экраны
```

## Установка

1. Скачайте репозиторий: кнопка «Code» → «Download ZIP», затем распакуйте архив.
2. Заархивируйте папку `game-dev` в файл `game-dev.zip`. Внутри архива должна быть папка `game-dev` с файлом `SKILL.md`.
3. В Claude.ai откройте настройки и загрузите архив как скилл. Точный путь в меню может отличаться, ориентируйтесь на раздел про скиллы или дополнения в вашей версии приложения.

## Примеры запросов

- игра про кота-прыгуна
- ловить падающие звёзды
- змейка с грибами
- собери яблоки, не трогая гнилые

## Управление в играх

- **Телефон:** тап или перетаскивание по экрану, кнопки паузы и звука в правом верхнем углу.
- **Компьютер:** стрелки или A/D для движения, P или Esc для паузы, M для звука, Enter для старта.

## Ограничения

Игры работают без интернета и без внешних библиотек. Рекорд хранится только во время сессии: после перезагрузки страницы он сбрасывается.
